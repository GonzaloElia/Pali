# components/

Markup de referencia de cada componente. Son fragmentos HTML para copiar a una pantalla; el CSS de cada uno vive en `css/components/<nombre>.css`.

| Archivo | Componente | CSS |
|---|---|---|
| `sidebar.html` | Barra lateral de navegación | `css/layout.css` |
| `button.html` | Botones | `css/components/button.css` |
| `chip.html` | Chips de estado | `css/components/chip.css` |
| `field-combo.html` | Buscador único de personas | `css/components/input.css` |
| `slot.html` | Turno de la agenda | `css/components/slot-grid.css` |
| `kpi.html` | Card de indicador | `css/components/card.css` |
| `table.html` | Tabla | `css/components/table.css` |
| `modal.html` | Modal | `css/components/modal.css` |

Ver todos renderizados en `../components.html`.
